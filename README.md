# Florence Dhaniel R. Ramales — Portfolio

A personal portfolio built with Next.js, React, Tailwind CSS, and Motion. It includes responsive project and About sections, a GhostFibers animated hero, scroll and text effects, and an interactive photo lanyard.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) while the development server is running.

## Deploy with Vercel

Import this GitHub repository into Vercel and keep the detected Next.js defaults. Vercel will install dependencies and build the site from the repository.
